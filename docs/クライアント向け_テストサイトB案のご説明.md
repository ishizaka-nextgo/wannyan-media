## 1. このサイトの考え方

- **読者**：犬・猫と暮らす30〜50代の女性を中心に想定しています。
- **見せ方**：写真を大きく使い、上質で落ち着いた雰囲気にしました。スマートフォンで読みやすいことを最優先にしています。
- **役割**：ペットショップのスタッフだからこそ書ける情報で、読者の悩みに答えるメディアです。読んだ方を、**LINE登録・店舗へのご来店・ご相談**につなげます。

## 3. 主な機能とねらい

### トップスライダー
- 写真5枚が **1.5秒 → 1.5秒 → 2秒 → 2.5秒 → 3秒** と、後ろへいくほどゆっくり切り替わります。
- 最初はテンポよく動いて目を引き、後半はコピーを読める長さで見せる、という設計です。
- 写真に重ねたコピーを押すと、ごはん・暮らし・お迎えガイド・図鑑などのページへ移動します。

### 記事（7カテゴリー）
- 食事・シニアケア・暮らし・健康・しつけ・お手入れ・季節のケアの7カテゴリーです。
- 記事は、冒頭の「この記事のポイント」、目次、チェックリスト、よくある質問、スタッフのおすすめ商品の順に読み進められる形です。
- 健康に関わる記事には、**「受診の目安」** と、獣医師の診察に代わるものではない旨の注意書きを入れています。

### 犬種・猫種図鑑
- 性格、お手入れ、向いている暮らし、**お迎えの前に確かめたいこと** をまとめています。
- 「お手入れの手間」「運動量」などを、スタッフの目安として5段階で表示しています。
- 各ページの最後に **「お店で相談できます」** の欄を置いています。お近くのお店にいない場合の取り寄せや、ほかの店舗からの移動のご相談につなげます。
- 生き物の販売は、店頭での対面説明が法律で決められています。そのため、ネットでの販売ではなく「お店に相談する」を出口にしています。

### はじめてのお迎えガイド
- 家族で話し合っておきたいこと、準備リスト（子犬用・子猫用）、お迎えの日の流れ、最初の1週間と1か月にすることをまとめています。
- はじめて迎える方の不安に寄りそい、フードやグッズのご相談、お迎え後のサポートにつなげます。

### イベント・キャンペーン
- 見本として2件を掲載しています。
  - **先着50名様に、おやつのお試しセットをプレゼント**（キャンペーン）
  - **愛犬・愛猫のマッサージ体験会　参加者募集**（イベント）
- どちらも、ページの最後は **LINEのボタン** です。お知らせを見た方が、そのままLINEに登録する流れになります。

### お店の看板犬・看板猫
- 各店で暮らす子のプロフィールとお店の名前を紹介し、「会いに行きたい」と思っていただくための枠です。
- 「販売しておりません」と明記し、販売の広告にならない見せ方にしています。

### うちの子ムービー
- 飼い主さんがスマートフォンで縦に撮った動画を、カード形式で並べています。
- 各動画に、**アカウント名・名前・年齢・撮影スポット** を表示します。
- 動画の列は **右から左へゆっくり自動で流れ**、たくさんの動画があることが一目で伝わります。
- 再生中や指で触れている間は止まります。止めるボタンも付けています。
- 下に **動画の募集（LINEから投稿）** の案内を置き、アンバサダーを増やす仕組みにしています。

### LINEへのご案内
- トップの途中と、フッターの上の2か所に置いています。
- 記事の最後、イベントのページ、メニューからも友だち追加できます。

## 4. 読者を集め、また来ていただく仕組み

| 目的 | サイトの仕組み |
|---|---|
| **新しい読者に見つけてもらう** | 悩みに答える記事、犬種・猫種図鑑、お迎えガイド（「柴犬 性格」「子犬 準備」などの検索からの入口） |
| **また見に来ていただく** | 新着記事、イベント・キャンペーン、うちの子ムービー、LINEでのお知らせ |
| **サイト内をめぐっていただく** | 記事→関連記事・図鑑、図鑑→関連記事・ほかの犬種、悩み・カテゴリー・メニューからの移動 |
| **ご来店・ご相談につなげる** | 各ページの「お店で相談できます」、看板犬・看板猫、店頭キャンペーン |
| **ファンを増やす** | うちの子ムービーへの動画投稿（アンバサダー） |

## 5. 品質について

- **スマートフォン対応**：スマートフォンでの見やすさを基準に作っています。
- **表示の速さ**：Google の品質チェック（Lighthouse）で、トップページは表示の速さ97点です。
- **使いやすさ**：アクセシビリティ（どなたにも使いやすいか）は100点です。文字と背景の色の差、ボタンの大きさ、読み上げ機能への対応を確認しています。
- 動きを減らす設定にしている方には、自動で動く表示を控えます。

## 6. 仮の内容について

テストサイトのため、次の内容は仮のものです。本番では、御社の情報に差し替えます。

- **リンク先**：店舗一覧・LINE公式アカウント・オンラインショップ。押すと「本番では○○につながります」と表示されます。
- **記事・図鑑・お迎えガイド**：見本として作成したものです。
- **イベント・キャンペーン**：日時・会場・内容は仮です。
- **看板犬・看板猫、うちの子ムービー**：名前・年齢・店舗名は仮です。
- **写真・動画**：確認用の素材です。
- **おすすめ商品**：仮の商品です。

## 7. 本番に向けてご相談したいこと

### ご用意いただきたいもの
- 店舗一覧・LINE公式アカウント・オンラインショップの正式なURL
- 看板犬・看板猫の写真とプロフィール、在籍店舗
- うちの子ムービーに掲載する動画と、投稿者の方の掲載許可
- イベント・キャンペーンの実際の内容

### 確認が必要なこと
- **獣医師の監修**：健康・図鑑・お迎えガイドの内容は、獣医師の監修を受けたうえで公開することをおすすめします。
- **キャンペーンの景品**：景品表示法で、景品の金額に上限があります。内容を決める際にご確認ください。
- **動画の投稿規約**：アンバサダー募集の前に、掲載の許可・肖像権・利用範囲を定めた規約ページを用意します。

### 今後の拡充のご提案
- **店舗ページ**：看板犬・スタッフ・サービス・地図をまとめ、地域の検索からのご来店につなげる
- **季節のケアカレンダー**：月ごとに気をつけたいことをまとめ、毎月見に来ていただくきっかけにする
- **記事の更新計画**：月ごとの本数とテーマを決め、検索からの入口を増やす
- **広告掲載のご案内**：業者様からの広告を募る場合は、案内ページと「PR」表示のルールを用意する
